# Mohanraj — Web Developer Portfolio

A responsive personal portfolio website showcasing Mohanraj's web development projects, technical skills, education, and contact section. Built with HTML, CSS, and vanilla JavaScript.

## Overview

This project is a static front-end portfolio with a dark visual style, animated interactions, and sections for projects, skills, about/education, and contact information.

## Features

- Responsive navigation and portfolio layout
- Project showcase with technology labels
- Animated technical-skill indicators
- About and education sections
- Contact form UI and social links
- Scroll progress indicator and interactive JavaScript effects

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins and Space Grotesk)
- Font Awesome icons

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/webwithmohan/portfolio-website.git
   ```

2. Open the project folder.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step is required.

## Projects Featured

The portfolio currently highlights interactive browser projects including:

- Stimulation Ball Movement
- Random Ball Movement
- Eye Ball Movement
- Pacman

Update each project's “Visit Website” link in `index.html` to its real live demo or repository URL before publishing. Replace placeholder links such as `https://example.com` so visitors can reach the actual projects.

## SEO and Discoverability

- The page includes a descriptive HTML title, meta description, and social-sharing metadata.
- Use meaningful visible headings and descriptive image `alt` text.
- Keep project descriptions accurate and link to the actual source repositories or live demos.
- Once the portfolio is deployed, add its real public URL to the repository's GitHub **About** website field and configure Google Search Console for that deployed domain.
- Add a sitemap and canonical URL only after the final public website URL is known.
